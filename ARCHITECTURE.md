# DataGuardian AI - Architecture

## Overview
Enterprise Data Leak Prevention System

## Components
1. File Scanner - Scans uploads for PII
2. Lyzr Agent - AI reasoning for risk scoring
3. Dashboard - Streamlit UI (app.py)
4. Compliance Engine - GDPR & DPDP Act mapping

## Flow
User Upload -> PII Detection -> Lyzr Agent Analysis -> Risk Score -> Report

## Tech Stack
- Python, Streamlit
- Lyzr Automata for Agent
- Regex + NLP for detection
